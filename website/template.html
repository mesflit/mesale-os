    What it is made of

    Debian 13
    The base system, with Debian's security updates.
    Kernel, Mesa, firmware
    From Debian backports.
    GNOME
    From Debian testing, with the libraries it needs.
    NVIDIA
    NVIDIA's own repository, for GTX 16, RTX and newer. Older cards use nouveau.
    File system
    ext4, btrfs or xfs, with optional encryption.
    Nix
    Artwork, packages, ISO tools and this page are built through one flake.

    Mesale OS is in development. GNOME and the libraries it pulls in come from Debian testing, so their security fixes can arrive later than in stable. Try it in a virtual machine first.

    Mesale is short for meşale, Turkish for torch.
