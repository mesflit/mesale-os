    Install

    Up and running in three steps

    1. Download

      Get the latest ISO from the releases page.

    2. Make a USB stick

      Write the ISO with GNOME Disks, balenaEtcher or Ventoy. This erases the stick.

    3. Boot and install

      Start from the stick. The installer opens by itself and asks for your wallpaper and features.

    Just curious? Try it in a virtual machine first. With Nix installed:

    git clone {{REPO}} && cd mesaleos && nix run

    Questions

    Good to know

    Is it ready for everyday use?

    Not yet. Mesale OS is in development. GNOME and the libraries it pulls in come from Debian testing, so their security fixes can arrive later than in stable. Try it in a virtual machine or on a spare computer first.

    Can I add or remove things after installing?

    Yes. Open Mesale Center, or run mesale-feature add and mesale-feature remove in a terminal. The feature list above writes that command for you.

    How do updates work?

    Debian packages update through Debian as usual. Mesale's own packages come from a signed repository that is rebuilt on every change.

    Does it work with my NVIDIA card?

    GTX 16, RTX and newer cards can use NVIDIA's driver, which is downloaded from NVIDIA only if you select it. Older cards use the open nouveau driver.

    Why is every release named after something in the sky?

    The desktop is all sky: clouds, dawn, dusk and night. So every release is named after a celestial body: a star, a planet, a moon. This one is “{{CODENAME}}”.

    What does the name mean?

    Mesale is short for meşale, Turkish for torch.
